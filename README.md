# CoppeliaSim_4.0

# 🤖 Simulações no CoppeliaSim – Robótica Industrial  
### 🎓 Repositório de Exemplos e Estudos de Simulação em Ambiente Virtual

Este repositório reúne simulações desenvolvidas no CoppeliaSim com foco em **robótica industrial, propriedades físicas e experimentação em ambiente virtual**.  
Ele funciona como um laboratório didático para alunos que desejam compreender, de forma prática, o comportamento de objetos simulados e robôs manipuladores.

---

## 📌 Objetivo do Repositório

Este repositório foi criado para:

- 🎯 Demonstrar conceitos fundamentais de robótica em simulação  
- ⚙️ Explorar propriedades físicas de objetos como massa, atrito e inércia  
- 📘 Auxiliar no ensino de cinemática e dinâmica  
- 🧪 Disponibilizar exemplos práticos modificáveis  
- 🛡️ Criar um ambiente seguro para testar comportamentos físico-mecânicos  

Cada simulação possui um propósito educativo próprio.

---

## 📂 Conteúdo do Repositório

As simulações contidas aqui incluem os seguintes tipos:

### 🧱 1. Propriedades dos Objetos  
Demonstra como alterações em propriedades físicas mudam o comportamento dos objetos.

Comportamentos observáveis:
- 🪨 Objetos pesados com queda mais marcante  
- 🧊 Objetos escorregadios com baixo atrito  
- 🟢 Esferas quicando com alta restituição  

Arquivo:  
`Aula_02_Propriedades.ttt`

---

### ⚡ 2. Interações Dinâmicas  
Cenas que mostram:

- 💥 Colisões  
- 🔄 Movimentos naturais  
- 🌀 Rolamento e deslizamento  
- 🧩 Estabilidade e centro de massa  

Perfeito para entender o comportamento do motor físico.

---

### 🤝 3. Manipulação de Objetos (se aplicável)  
Simulações com robôs manipuladores interagindo com objetos.

Exemplos:
- 🤏 Pegada em objetos leves x pesados  
- 🧱 Manipulação de objetos instáveis  
- 🔧 Ajuste de força, velocidade e precisão

## ▶️ Como Executar as Simulações

1. 💻 Instale o **CoppeliaSim (versão EDU)**  
2. ⬇️ Baixe qualquer arquivo `.ttt` deste repositório  
3. 📂 Abra o CoppeliaSim:  
   `File → Open Scene…`  
4. ▶️ Clique em **Play** para iniciar  
5. 🔧 Ajuste propriedades como:  
   - massa  
   - atrito  
   - densidade  
   - restituição  
   - inércia  

O comportamento muda imediatamente ao alterar os parâmetros.
